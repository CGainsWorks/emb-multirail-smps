# test-results

**Nothing in this directory was measured.**

No board has been fabricated, assembled, powered or probed. Every file here is
the output of a model running on a desktop machine. The directory is called
`test-results` because that is the layout the project brief asks for, not
because anything was tested on hardware.

Everything here is regenerated by `make demo`, and CI fails if what is
committed has drifted from what the code produces.

| directory | what it holds | how it was produced |
|---|---|---|
| `bode/` | Loop gain of each rail, hand derived model against switching simulation, plus the margins table and the raw swept data | Analytic loop from state space averaging; simulated loop measured by injection into a cycle accurate switching simulation |
| `load-regulation/` | Output voltage and ripple against load | Switching simulation run to steady state at each load |
| `line-regulation/` | Output voltage against input voltage | Same, swept over the input range |
| `transient/` | Load step response | Switching simulation with a current source step, which is what an electronic load does |
| `efficiency/` | Per stage and whole board efficiency, and the loss breakdown | Analytic loss model, term by term. See `docs/loss_model.md` for how wrong each term is likely to be |
| `thermal/` | Junction temperatures and the ambient derating curve | Two resistance lumped model. See `docs/thermal_model.md` |
| `emc-prescan/` | Conducted emissions spectrum against a reference envelope, and the input filter interaction check | Harmonic model of the input current through the filter and a LISN. Differential mode only |
| `power_tree.png` | The power tree with the currents and efficiencies each stage actually sees | Loss model solved backwards from the leaves |

When measurements are eventually taken they belong here alongside these, in
files clearly named as measured, with the predictions kept rather than
overwritten. The comparison between a prediction made before the board and a
measurement made after it is the only thing that makes either interesting.
